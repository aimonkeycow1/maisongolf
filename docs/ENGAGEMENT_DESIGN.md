# Maison Golf · 使用者黏著／習慣養成設計需求

> 角色：頂級行為心理學家 + 頂級軟體工程師
> 目標：用「合乎人性、可長期留存」的方式，讓球友自然養成「每次打完球就回來記分、回訪查看成長」的習慣。
> 立場：**健康黏著（healthy engagement）**，非剝削式設計。所有機制都應提升使用者的真實價值（記錄、進步、社交），而不是製造焦慮或欺騙。

---

## 一、行為模型總綱：Hook Model（上癮模型）

整個產品圍繞 Nir Eyal 的 **觸發 → 行動 → 變動獎賞 → 投入** 循環設計，並疊加 3 個強化心理槓桿。

| 階段 | 心理機制 | 在 Maison Golf 的落地 |
|------|----------|------------------------|
| **Trigger 觸發** | 外部觸發 + 內部觸發（情緒） | 打完球的成就感／不甘心 → 想記分；連續週數快斷 → 回訪 |
| **Action 行動** | 降低行動門檻（Fogg 行為模型 B=MAP） | 首頁超大「立即錄分」CTA、草稿續打、一鍵恢復 |
| **Variable Reward 變動獎賞** | 多巴胺由「不確定性」驅動 | AI 教練每次講評不同、是否破紀錄、是否解鎖成就、排行榜名次變動 |
| **Investment 投入** | 沉沒成本 + 宜家效應（自己累積的更珍惜） | 歷史戰績、連續週數、成就牆、個人最佳——越用越捨不得離開 |

## 二、9 大心理槓桿 → 功能需求

### 1. 連續性 / 損失厭惡（Loss Aversion + Streak）
- **原理**：失去比得到更痛（約 2 倍）。一旦累積「連續 N 週」，使用者會為「不想中斷」而回訪。
- **需求**：
  - 計算「連續出場週數」(streak)。
  - 狀態三態：`active`（本週已記分）、`at_risk`（上週有、本週還沒）、`broken`（已中斷）。
  - `at_risk` 時首頁顯示**挽留橫幅**：「你已連續 X 週出場，本週還沒記分，別讓連勝中斷！」
  - 火焰圖示強化「熱度」隱喻。

### 2. 成就感 / 完成欲（Achievement + Completionism）
- **原理**：徽章/收集觸發「想集滿」的完成欲（Zeigarnik 未竟事務）。
- **需求**：
  - 成就牆：首場、10 場、25 場、首抓 Birdie、首抓 Eagle、同組奪冠、零爆洞、後九逆襲、突破個人門檻、連續 4 週。
  - 已解鎖（亮）vs 未解鎖（灰＋進度）。
  - 解鎖瞬間應有慶祝感（高亮、emoji）。

### 3. 目標漸進效應（Goal-Gradient + Endowed Progress）
- **原理**：越接近目標越想完成；「已有進度」比「從零開始」更易啟動。
- **需求**：
  - 每個未解鎖成就顯示**進度條**（如 7/10 場）。
  - 首頁主打「最接近達成」的下一個目標（差一點就解鎖 → 高啟動）。
  - 等級制天然給予「起始進度」，不從空白開始。

### 4. 身份認同（Identity）
- **原理**：人會為「維持自我形象」而行動（「我是一個會進步的球手」）。
- **需求**：
  - 依個人最佳成績給予**球手等級與稱號**（歡樂高球 → 穩定成長 → 進階球手 → 單位數差點 → 巡迴賽水準 → Scratch 殺手）。
  - 等級顯著展示（環形進度 + 稱號），成為使用者的「身份標籤」。

### 5. 社交比較 / 競爭（Social Comparison）
- **原理**：高爾夫本質社交；與同儕比較是最強回訪動機之一。
- **需求**：
  - 排行榜（已有）強化「我的名次」高亮。
  - 對戰紀錄（head-to-head）與「本月名次變化」（後續可擴充）。
  - 分享戰報（已有）→ 外部社交觸發回流。

### 6. 變動獎賞（Variable Reward）
- **原理**：固定獎賞會鈍化，隨機/不確定獎賞維持多巴胺。
- **需求**：
  - AI 教練每場講評內容不同（已具備）。
  - 「是否破個人紀錄／解鎖新成就」本身就是不確定獎賞，需即時顯著回饋。

### 7. 即時回饋 + 進步可視化（Progress Visualization）
- **原理**：看得見的進步＝持續動力。
- **需求**：
  - 最近 5 場趨勢圖（已有）。
  - 「距離破個人紀錄還差 X 桿」具體提示。

### 8. 未竟任務（Zeigarnik Effect）
- **原理**：未完成的任務會盤旋在腦中，驅使回來完成。
- **需求**：
  - 未完成的記分草稿，首頁顯著提示「你有一場未完成的記分，繼續？」。
  - 「本月目標」未達成時持續提示進度。

### 9. 稀缺 / 期限（Scarcity / FOMO）
- **原理**：有期限的目標提升急迫感。
- **需求**：
  - 「本月還有 X 天」配合月度場次目標。
  - 注意：適度即可，避免製造過度焦慮。

## 三、首頁資訊架構（依「啟動優先序」排列）

1. **挽留橫幅**（僅 streak `at_risk` 或有未完成草稿時出現）— 最高優先，觸發回訪行動。
2. **成長儀表板**：等級稱號 + 環形進度、連續週數（火焰）、本月場次目標、距離破紀錄差距。
3. **下一個成就**（最接近達成）+ 成就牆預覽。
4. 立即錄分 CTA（降低行動門檻）。
5. 歷史戰績（投入/沉沒成本展示）。

## 四、工程實作對應

| 需求 | 實作位置 |
|------|----------|
| 連續週、等級、成就、里程碑、nudge 計算 | `engagement.py`（純函式，從使用者場次計算，無需改 DB） |
| 成長 UI 元件（等級環/徽章/進度條/連勝/橫幅） | `templates/_macros.html` |
| 首頁接入 | `app.py` `index()` 路由 + `templates/index.html` |
| 資料來源 | `load_rounds_visible_to_user(current_user)` + `get_player_in_round_for_user`（聚焦當前使用者） |

> 設計原則：所有指標**即時從既有場次資料計算**，不新增資料表、不破壞現有流程，零遷移風險。

---

## 五、倫理護欄（必守）

- 不製造虛假稀缺、不偽造他人動態、不用欺騙性倒數。
- 挽留提示語氣正向（「保持節奏」），而非羞辱（「你又偷懶了」）。
- 所有機制服務於使用者的真實目標：記錄球技、看到進步、與球友同樂。
- 不引導非理性消費或賭博行為。
